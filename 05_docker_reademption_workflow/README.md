## 🔬 Overview
This project showcases a **Container-First** approach to transcriptomics. By utilizing **Docker**, I have encapsulated the entire **READemption** environment—including its complex dependencies like `segemehl` and `DESeq2`—into a portable unit. This ensures that the analysis performed today on my machine will yield identical results years from now on any server worldwide.

---

## ⚓ Why Containerization?
In modern bioinformatics, "Dependency Hell" is a major barrier to reproducible research. This project solves that by:
- **🛠️ Absolute Reproducibility:** Every tool version, library, and environment variable is locked within the Docker image.
- **🚀 Portability:** The entire workflow can be launched on a laptop, a HPC cluster, or the cloud with a single command.
- **🛡️ Isolation:** No need to install complex tools on the host system; the container remains isolated and clean.

---

## 🛠️ Project Architecture
The project is structured into logical layers:

- **`launch_docker_workflow.sh`**: The main entry point that pulls the image and initializes the container.
- **`scripts/`**:
    - `install_docker_engine.sh`: Professional automation for setting up the Docker environment on Linux.
    - `run_container_pipeline.sh`: The core RNA-Seq analysis logic (Salmonella benchmark) executed within the container.
- **`visualizations/`**: curated results generated by the containerized run.

---

## 🚀 Usage Guide

### 1. Host Preparation
Ensure Docker is installed on your Linux system:
```bash
bash scripts/install_docker_engine.sh
```

### 2. Launch the Workflow
Execute the launcher script to pull the image and start the container:
```bash
bash launch_docker_workflow.sh
```

### 3. Run analysis (Inside Container)
Once inside the container, initiate the automated pipeline:
```bash
bash scripts/run_container_pipeline.sh
```
